# VA Tracker

Extension Chrome perso qui garde le fil des épisodes d'anime regardés sur voiranime.cx.

## Installer sur un PC

```bash
git clone git@github.com:EnzoPasselegue1/VA-Ext.git
```

1. Ouvrir `chrome://extensions`
2. Activer le **Mode développeur** (en haut à droite)
3. **Charger l'extension non empaquetée** → choisir le dossier `VA-Ext`

La progression se synchronise entre les PC via le compte Google
(Chrome connecté + synchronisation des **Extensions** activée).

## Mettre à jour

```bash
cd VA-Ext && git pull
```

Puis cliquer sur ↻ de VA Tracker dans `chrome://extensions`.
